# CP-CODE-TEMPLATE

This repository contains my Java template for Competitive Programming.

I use this template for solving problems on platforms like:

- LeetCode
- Codeforces
- CodeChef
- HackerRank

## Features

- Fast Input
- PrintWriter Output
- GCD
- LCM
- Binary Exponentiation
- Reverse Array
- Print Array
- Multiple Test Case Support

## How to Use

1. Clone the repository.
2. Open `Main.java`.
3. Write the solution inside `solve()`.
4. Uncomment the test case line if the problem has multiple test cases.
